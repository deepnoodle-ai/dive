## Highlights

Dive v1.44.0 refreshes model catalogs across Anthropic, Google, OpenAI, Meta,
xAI, and Mistral with the latest GA/preview chat, audio, and image models, and
updates deprecated and retired model statuses. New recommended defaults in the
`dive` CLI include `claude-fable-5-2`, `gemini-4-carbon`, `gemini-4-hydrogen`,
`gpt-6.1-terra`, and `muse-ember-1.0`. Note that `claude-fable-5-2`,
`gemini-4-carbon`, `gemini-4-hydrogen`, `gpt-6.1-terra`, and `muse-ember-1.0`
were not probed against live provider APIs in this release; `gpt-6.1-terra` is
registered for the OpenAI Responses API only.

This release also upgrades Wonton from v0.2.1 to v0.10.2 across every Dive
module. When stdout is not a terminal, the `dive` CLI now prints plain text
without ANSI escape codes, while terminal output remains unchanged.

`WebFetch` with `MaxRetries` set no longer retries 404 or 403 responses,
retrying only errors that `fetch.IsRetryable` accepts and reporting the attempt
count in its error. No code changes are required to upgrade.

## Changelog

### Added

- **New provider models and deprecations.** Added `claude-fable-5-2` and
  `claude-mythos-5-2` (Anthropic); `gemini-4-carbon`, `gemini-4-hydrogen`, and
  `gemini-omni-1.2-flash` (Google); `gpt-6.1-terra`, `gpt-image-2.6-sunburst`,
  and `gpt-image-2.6-flare` (OpenAI); `muse-ember-1.0` (Meta); `grok-voice-3.0`
  and `grok-voice-2.0` (xAI); and the Voxtral 3 audio preview models
  (`voxtral-mini-transcribe-3-0`, `voxtral-mini-transcribe-realtime-3-0`,
  `voxtral-small-transcribe-3-0`, `voxtral-mini-tts-3-0`) (Mistral). Marked
  `gemini-2.5-pro`, `gemini-2.5-flash`, `gemini-omni-1.1-flash`, and
  `grok-voice-2.0` deprecated, and `gemini-2.5-flash-image` and
  `grok-imagine-image-quality` retired.

### Changed

- **Wonton v0.10.2.** The `dive` CLI prints plain text, with no escape codes,
  when stdout is not a terminal.

### Fixed

- **WebFetch no longer retries a 404 or 403** when `MaxRetries` is set. It
  retries only errors that `fetch.IsRetryable` accepts, and its error states
  the number of attempts it made.
