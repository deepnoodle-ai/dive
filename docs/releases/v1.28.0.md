## Highlights

**The experimental CLI is now designed to stay open as a daily workspace.** It
starts in the managed, scrollable screen by default, remembers input history,
model, reasoning effort, thinking visibility, and usage-detail preferences, and
keeps the active model and effort visible. This changes the default behavior for
existing CLI users. Use `--inline` or `DIVE_INLINE=1` when you need the
terminal-native renderer instead.

**The managed screen now restores the terminal conveniences that an alternate
screen normally takes away.** You can select and copy transcript text, copy code
blocks by command, send the conversation to terminal scrollback, expand tool
results, and keep the transcript on exit. The status area is intentionally
compact, while detailed token usage remains available on demand. The Bash tool
also has a simpler result contract: successful calls return only their merged
output, and failures return the exit code and output inside an `<error>` tag.

**Dive now supports Meta's Model API as a first-party provider.** The new
`providers/meta` module covers Muse Spark text models, grounded web search, Muse
Image generation and editing, and Muse Voice transcription. Muse Spark uses the
Responses API so encrypted reasoning can survive tool turns. The discounted
`-contributor` model tier is available only by explicit model ID because its
lower price permits Meta to train on prompts and completions.

**Reasoning and tool replay are safer across the provider layer.** Responses
providers request encrypted reasoning whenever the selected model reasons,
web-search calls retain their query and result details, and OpenAI-compatible
providers now honor requests to disable parallel tool calls.

## Changelog

### Added

- **Expanded experimental CLI.** Added persistent input history and preferences,
  managed scrolling and selection, transcript and code copying, and commands
  such as `/model`, `/status`, and `/copy`.
- **Meta Model API provider.** Added Muse Spark reasoning, grounded search,
  image generation and editing, and voice transcription. Discounted contributor
  models permit Meta to train on prompts and completions.

### Changed

- **The managed screen is now the CLI default.** Use `--inline` or
  `DIVE_INLINE=1` for the previous renderer and `--print` for non-interactive
  use.
- **Simpler CLI presentation.** Startup, status, usage, and color styling are
  more compact and consistent.
- **Simpler Bash tool results.** Successful calls return the merged output
  directly; failed calls include the exit code and output in an `<error>` tag.
- **Model-aware compaction.** The automatic threshold now scales with the
  selected model's usable context window.

### Fixed

- **CLI reliability and polish.** Fixed navigation, model propagation,
  compaction responsiveness, and several session and rendering edge cases.
- **Responses provider replay.** Encrypted reasoning and web-search details now
  survive tool turns.
- **OpenAI-compatible parallel tool control.** `llm.WithParallelToolCalls` is
  now included in Chat Completions requests.
