## Highlights

This patch restores Claude turns in conversations that previously used Gemini.
Gemini may save an empty text part with a thought signature; Claude rejects that
part when Dive replays the history. Dive now omits it from Anthropic requests
while leaving the stored conversation intact.

Upgrade to v1.33.1 to continue those conversations on Claude without starting
a new one. The same request conversion is used by Dive's Ollama provider.
