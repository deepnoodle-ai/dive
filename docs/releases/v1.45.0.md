## Highlights

Dive v1.45.0 adds OpenAI's GPT-6.2 Astra and Sol (`openai.ModelGPT62Astra`,
`openai.ModelGPT62Sol`) and Google's `gemini-nano-banana-2.1` image model.
Reasoning settings for GPT-6.1 Terra and Gemini 4 Carbon and Hydrogen are now
adjusted to what each model accepts, rather than forwarded unchecked.

Media generation catches up with provider shutdowns. Grok video works again on
xAI's native video API and reports its cost in `Metadata["cost_usd"]`. OpenAI
shut down Sora, so `openai.MediaProvider.GenerateVideo` is removed. Google shut
down Imagen, so an `imagen-` model now returns an error. Veo runs only on Vertex
AI: use `google.NewMediaProvider(google.WithMediaVertexAI(location))`. These
calls already failed at runtime, but code that calls `GenerateVideo` on the
OpenAI provider no longer compiles. Switch to `grok-imagine-video` for video and
a Gemini image model for images.

Every module moves to current dependencies: Wonton v0.14.2, openai-go v3.101.0,
genai v1.77.0, a2a-go v2.9.0, mcp-go v1.5.0, and OpenTelemetry 1.47. The `dive`
CLI now exits 2 on a usage error, and defaults to `grok-imagine-video` for
`dive video`.

## Changelog

### Added

- **GPT-6.2 Astra and Sol.** `openai.ModelGPT62Astra` and `ModelGPT62Sol` are
  the recommended OpenAI models; new Google, Mistral, and OpenRouter models too.

### Changed

- **Verified reasoning controls.** GPT-6.1 Terra and Gemini 4 Carbon and
  Hydrogen now get unsupported effort levels and thinking budgets adjusted.
- **Dependency upgrades.** Wonton v0.14.2, openai-go v3.101.0, genai v1.77.0,
  a2a-go v2.9.0, mcp-go v1.5.0, and OpenTelemetry 1.47. The `dive` CLI exits 2
  on a usage error.
- **`dive video` defaults to `grok-imagine-video`** and `dive image` with only a
  Google key defaults to `gemini-3.1-flash-image`.
- **`google.WithMediaImagenLocation` is deprecated** and does nothing.

### Fixed

- **Grok video generation works again.** It uses xAI's native
  `/v1/videos/generations` API and reports the cost in `Metadata["cost_usd"]`.
- **A Gemini image response with no image names its finish reason**, such as
  `IMAGE_RECITATION`.

### Removed

- **Breaking: `openai.MediaProvider.GenerateVideo` and the `sora-` models.**
  OpenAI shut down Sora and the Videos API on 2026-09-24. Use
  `grok-imagine-video`.
- **Breaking: Imagen models.** Google shut down Imagen. An `imagen-` model
  returns an error; use a Gemini image model. Veo runs only on Vertex AI now.
