## Highlights

Claude can now see a token budget for a whole turn. `max_tokens` caps each
response, but the model cannot see it, so a long thinking pass can use the
whole cap and write no answer. Set `ModelSettings.TaskBudget` and the model
sees the budget count down as it thinks, calls tools, reads tool results, and
writes, and it finishes within the budget. Dive sends the Anthropic beta header
for you.

```go
ModelSettings: &dive.ModelSettings{
    ReasoningEffort: llm.ReasoningEffortMedium,
    TaskBudget:      &llm.TaskBudget{Total: 40000},
}
```

Every model call of one `CreateResponse` shares the budget. If a PreIteration
hook compacts the turn's history, Dive sends the remaining budget so the
countdown continues. Tool results count against the budget, so size it from
measured turns. Task budgets work on Opus 4.7 and later, Sonnet 5.5, Haiku
5.5, and Fable 5 and 5.1. Other models and providers drop the setting and log
a warning, and a total below 20,000 is an error.

The change is additive: existing code needs no changes.
