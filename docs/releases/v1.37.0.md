## Highlights

Gemini 4 Argon, Google's new flagship reasoning model, joins the Google and
OpenRouter catalogs and becomes the CLI's Gemini pro model. Its thinking
settings were probed against the live API. Cost estimates use Google's launch
rates, which double on 2026-12-01.

Meta's Muse Wonder 1.0 (preview) takes reasoning effort up to `max`. It accepts
only an automatic tool choice, so give `dive.PromptStopHook` and
`dive.PromptToolGate` a different model.

Gemini 3.5 Flash and 3.7 Flash are deprecated. The CLI now defaults to Gemini
3.8 Flash when only a Gemini key is set.

Upgrade the root module and any Dive provider or integration modules together
to `v1.37.0`.

## Changelog

### Added

- **Gemini 4 Argon.** `google.ModelGemini4Argon` and
  `openrouter.ModelGemini4Argon`, at launch pricing. It takes the CLI's Gemini
  pro slot from Gemini 3.1 Pro.
- **Muse Wonder 1.0.** `meta.ModelMuseWonder10` (preview), with efforts
  `minimal` through `max`. It accepts only an automatic tool choice, so
  `dive.PromptStopHook` and `dive.PromptToolGate` need another model.

### Changed

- **Gemini defaults move off deprecated models.** The CLI defaults to
  `gemini-3.8-flash`, and Google transcription to `gemini-3.6-flash`.

### Deprecated

- **`google.ModelGemini35Flash` and `google.ModelGemini37Flash`.** Google routes
  them to `ModelGemini36Flash` and `ModelGemini38Flash`.
