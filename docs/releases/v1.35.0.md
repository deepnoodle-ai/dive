## Highlights

Dive now exposes 30 more model IDs across seven providers, including GPT-6.1
Sol, Claude Sonnet 5.5, and both Gemini 3.8 speech models. The CLI recommends the
new OpenAI and Anthropic models, while chat defaults remain unchanged. Catalog
prices reflect current provider listings, including OpenRouter route and cache
rates. Gemini 4 Argon remains outside the catalog because no public API ID was
confirmed.

Request settings now follow the new models' contracts. GPT-6.1 Sol accepts
reasoning effort from `low` through `max` and omits unsupported temperature.
Sonnet 5.5 maps disabled thinking to `between_tools`, preserves the effort values
previously serialized in conversation history, and rejects incompatible effort
changes before HTTP. Keep adaptive thinking when a conversation's historical
effort levels differ. Signed thinking requires append-only history. OpenAI's
`priority`, `fast`, and `ultrafast` tiers are accepted, but cost estimates still
use standard-tier rates.

Direct Google speech-provider calls now default to stable Gemini 3.8 Flash-Lite
TTS. You can also select Gemini 3.8 Flash TTS explicitly. Audio output prices
remain separate from Dive's text-token pricing schema. Upgrade the root module
and any Dive provider or integration modules together to `v1.35.0`.

## Changelog

### Added

- **Latest model catalogs.** GPT-6.1 Sol, Claude Sonnet 5.5, Gemini 3.8 TTS,
  GLM 5.3 and Leanstral on Mistral, plus new DeepInfra, Ollama, and OpenRouter routes.
- **OpenAI service tiers.** `WithServiceTier` accepts `priority`, `fast`, and
  `ultrafast`; catalog cost estimates continue to use standard-tier rates.

### Changed

- **Model request compatibility.** Sonnet 5.5 uses `between_tools` for disabled
  thinking and rejects incompatible effort history without rewriting it.
  GPT-6.1 Sol uses `low` through `max` effort and explicit prompt caching.
- **Google speech default.** Direct speech-provider calls use Gemini 3.8
  Flash-Lite TTS. OpenRouter catalog rates reflect current public listings.
